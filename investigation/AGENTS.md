# Investigation-only directory

This directory is for repeatable local analysis of the exact ATM10 8.2 environment.

- Client files, MOD jars, extracted classes, decompiled output, generated reports, caches, and other binaries are local-only and must remain ignored.
- Do not commit Minecraft or MOD binaries, class files, decompilation output, or downloaded archives.
- Commit only small, reproducible scripts or human-readable metadata when it is useful for future updates.
- Scripts must identify the exact pack version and file/project IDs they analyze, and must not silently fall back to a different MOD version.
